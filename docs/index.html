      A short introduction

      What is a conditional random field?

      PRONAUXVERB
      Icanfish

      Observed words and features inform each label; neighboring labels are connected.

      A CRF is a discriminative, undirected probabilistic graph model. In a linear-chain CRF, each output label is a node connected to the labels beside it. It extends the idea of logistic regression from one classification to an interconnected sequence of classifications.

      That structure makes CRFs useful for sequence labeling: part-of-speech tagging, named entity recognition (NER), and other tasks where nearby labels and observations carry information. This demo combines feature weights with adjacent-tag transition weights, then uses Viterbi decoding to choose the highest-scoring complete path.

      About this implementation

      Training happens offline in Python. This static page downloads the exported labels, state-feature weights, and transition weights, ports the same feature extraction to JavaScript, and runs first-order Viterbi decoding locally. It does not run sklearn-crfsuite in the browser or substitute a different model.
